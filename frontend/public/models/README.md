# YOLO11 nano model

`yolo11n.onnx` is the pretrained object detection model from [Ultralytics assets](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.onnx). It predicts COCO object classes, not waste categories or material composition.

SHA-256: `634279b40c07c6391472c51ad45b81ebc48706a9a1fe72dd3396322acd0c053b`

Ultralytics distributes YOLO models under [AGPL-3.0 or an enterprise license](https://www.ultralytics.com/license). Re-Intent includes the model in the browser application under AGPL-3.0 and keeps the final item choice with the user. The project's license text is in the repository root `LICENSE` file.
